# Start Development Server

Use `bun run prisma:seed` command to fill the database with initialize test data such as a tenant (store) and its
accounts

After initializing the Database you can use localhost server with port 3000 and this address to enter stores login page:
`localhost:3000/store/zzz-dev-hq/admin/login` using this username: `zzz-dev-admin` and password: `1234` combination.
